# fhtechnikum-pm1-concert-finder

A console .NET application that helps you find upcoming concerts for your favorite music band in your city.

## Quick start

Install the .NET 8 SDK and add your Ticketmaster API key in `Program.cs`. Then run:

```bash
dotnet build ConcertFinder.csproj
dotnet run --project ConcertFinder.csproj
```

Run the standalone tests with:

```bash
dotnet run --project ConcertFinder.TestRunner/ConcertFinder.TestRunner.csproj
```
